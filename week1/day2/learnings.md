# Day 2 Learnings

Based on today's tasks, this is what I learned:

## 1. HTML5 Semantics and Accessibility
- I learned how to structure a page with semantic tags like `header`, `nav`, `main`, `section`, `aside`, and `footer`.
- I understood why semantic HTML helps both accessibility and SEO.
- I practiced organizing content with a cleaner hierarchy that is easier to read and maintain.

## 2. Advanced CSS Layouts
- I used CSS Grid to create a two-column dashboard layout (sidebar + content).
- I used Flexbox for alignment in navigation and for spacing menu items.
- I saw when Grid is better for overall page layout and when Flexbox is better for component-level alignment.

## 3. CSS Variables and Reusable Styling
- I learned to define reusable design tokens in `:root` (colors, radius, shadow, transitions).
- I used custom properties to keep styles consistent and easier to update.
- I improved maintainability by avoiding repeated hardcoded values.

## 4. Animations and Transitions
- I implemented hover effects and transitions to make UI interactions smoother.
- I used keyframe animations (`fadeInUp`) to improve visual presentation of cards.
- I learned how subtle motion can improve user experience without being distracting.

## 5. Responsive Design
- I added media queries to adapt layout for smaller screens.
- I changed navigation and dashboard grid behavior for mobile usability.
- I learned to test and think mobile-first for better cross-device experience.

## 6. JavaScript Interactivity
- I implemented smooth scrolling for navigation links.
- I added dynamic card loading animation with delays.
- I added sidebar hover interactions to make the dashboard feel more interactive.

## Summary
Today helped me connect structure (HTML), presentation (CSS), and behavior (JavaScript) to build a modern, responsive dashboard interface.
